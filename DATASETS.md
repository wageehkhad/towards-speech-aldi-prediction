# Obtaining the datasets

None of the audio is redistributed here. This file covers how to obtain each
corpus and where to place it so the scripts find it with their default paths.
The expected directory layout is in `assets/README.md`.

## SADA (training and in-domain test)

435 hours of manually transcribed Arabic speech from Saudi Broadcasting
Authority television. The training split (417.6 h) is used for fine-tuning and
the test split (10.8 h) as the in-domain test set.

- Used by the scripts: https://huggingface.co/datasets/MohamedRashad/SADA22
  (the `--dataset` default in `download_sada.py`)
- Original release: https://www.kaggle.com/datasets/sdaiancai/sada2022

`download_sada.py` loads the corpus through `datasets.load_dataset`, writes the
audio under `assets/sada/wavs/`, and exports a manifest with audio paths,
durations and transcripts:

```bash
cd aldi_whisper_sada_scripts
python download_sada.py
python score_sada_aldi.py    # adds the silver-standard ALDi targets
```

The labelled manifests are already shipped in `assets/sada/`, so if you only
need to re-score or re-evaluate you can supply the audio and skip the export.

## MediaSpeech (MSA broadcast test)

10 hours of transcribed Arabic from the Al-Arabiya, France 24 Arabic and BBC
News Arabic YouTube channels. Used to test whether the models assign low ALDi
to MSA.

- Source: https://www.openslr.org/108/
- Access: direct download, no account required.

Place the audio under `assets/mediaspeech/`. The scored manifest
`manifest_mediaspeech_ar_aldi.csv` is shipped, so the ALDi targets do not need
to be recomputed; the `path` column must resolve to your local audio.

## Casablanca (out-of-domain multi-dialect test)

Eight Arabic dialects across four regions, roughly one hour per country. Used
for the out-of-domain evaluation in Table 2.

- Source: https://huggingface.co/datasets/UBC-NLP/Casablanca
- Access: Hugging Face account and accepting the dataset terms.

The evaluation scripts read a locally saved copy, so download the split you
need and persist it with `save_to_disk` to
`assets/casablanca/casablanca_audio_aldi`. Casablanca is published per country,
so check the dataset card for the config names before loading.

`casablanca_aldi_scored.csv` with the silver-standard targets is shipped.

## YouTube genre-validation clips

1,791 fifteen-second clips drawn from 49 public YouTube sources across six
genres, used for the genre validation in the paper.

The audio is not redistributed. What defines the set is
`assets/genre_based_aldi/sources.csv`, which gives the URL, genre, dialect
region and exact time window for every source, plus a deterministic
segmentation:

```bash
cd genre_based_aldi_experiments_scripts
python download_youtube_audio.py   # fetches only the window in sources.csv, 16 kHz mono
python segment_audio.py            # fixed 15 s windows, drops any tail under 5 s
```

Clips are named `<source_id>__clip<NNNN>.wav` by position, so the same source
audio always yields the same clip set.

**Three of the 49 videos have since been removed by their uploaders**, so the
full 1,791 cannot be regenerated from YouTube today. Their URLs are retained in
`sources.csv` for the record.

The definitive record of the clip set is
`assets/genre_based_aldi/clip_manifest.csv`: one row per clip, giving its clip
id, source, genre, dialect region, source URL, and the absolute time span the
clip occupies in the original video. It is regenerated by

```bash
python genre_based_aldi_experiments_scripts/build_clip_manifest.py
```

Per-clip predicted scores are not included; the per-genre and per-source
aggregates are in `results/genre_based_aldi/`.
